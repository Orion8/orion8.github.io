# The Mathematical Theory of Communication

English poster completed on 2026-10-12 for catalogue ID 2. Authors: Claude E. Shannon and Warren Weaver. Original book publication: 1949. Shannon's technical paper appeared in 1948.

## Editorial decisions

The book combines Weaver's opening exposition with Shannon's technical account. The poster distinguishes these authors' contributions. Shannon's five parts are shown as parts, not as five chapters or a fabricated chapter count. The part labels are shortened for readability:

| Part | Original heading | Poster focus |
| --- | --- | --- |
| I | Discrete Noiseless Systems | Source statistics, entropy and compression |
| II | The Discrete Channel with Noise | Capacity and reliable coding |
| III | Continuous Information | Signal ensembles and differential entropy |
| IV | The Continuous Channel | Bandwidth, power and noise |
| V | The Rate for a Continuous Source | Rate needed for an allowed reproduction distortion |

The five communication components and the separate noise input are drawn in a precise vector layer. The machine illustration is decorative and is not a circuit diagram. The entropy formula uses base 2. The one-bit example specifies an independent fair binary choice. The capacity statement is an asymptotic coding result under the channel/source assumptions of the theory. It does not claim zero errors in every finite message or give a practical code construction. R and C are explicitly stated to require the same rate units.
